# 🚀 Assignment Hub (iframe Dashboard)

A lightweight, responsive portfolio and dashboard interface built using HTML and CSS[cite: 1]. This project features a split-screen layout designed to easily navigate and preview multiple web development assignments from a single central hub without leaving the page[cite: 1].

## ✨ Features

* **📱 Split-Screen Dashboard Layout:** The viewport is cleanly divided into a sidebar menu (30% width) and a main preview area (70% width) using CSS Flexbox[cite: 1].
* **🔗 Interactive Navigation:** Sidebar buttons feature styled anchor links targeting an embedded `<iframe>`, loading external assignments seamlessly[cite: 1].
* **🎨 Clean & Modern UI:** Styled with customized flex container properties, styled action buttons with rounded designs, and a fixed height layout[cite: 1].

## 📂 File Structure

* `iframe.html` - The main dashboard file containing the structural layout, embedded iframe, and embedded CSS styling[cite: 1].

## 📚 Included Assignments

The dashboard currently links to the following project modules:
* **Assignment 1 & 6:** 🌄 Background Customization Project[cite: 1]
* **Assignment 2 & 7:** 📰 Newspaper Layout Project[cite: 1]
* **Assignment 3 & 8:** 📐 CSS Flexbox Layout Project[cite: 1]

* **Assignment 5 & 10:** 👤 Profile Card Component[cite: 1]

## 🚀 How to Use

1. Clone or download this repository.
2. Open `iframe.html` in any modern web browser.
3. Click any of the assignment buttons on the left sidebar to preview the respective project instantly inside the iframe panel on the right[cite: 1].
